# Шагрень

Интернет-магазин изделий из кожи с акцентом на персонализацию и аккуратную подачу продукции.

Проект сделан как полноценный демонстрационный магазин для портфолио: с адаптивным интерфейсом, каталогом товаров и визуальным стилем небольшого ремесленного бренда.

## О проекте

«Шагрень» — концепт магазина кожаных изделий.

Основной задачей было сделать сайт, который не выглядит как стандартный шаблон интернет-магазина: спокойная типографика, сдержанная цветовая палитра, крупные фотографии продукции и минимум лишних элементов в интерфейсе.

Отдельное внимание уделено адаптивности и тому, чтобы сайт одинаково аккуратно выглядел как на большом экране, так и на мобильных устройствах.

## Возможности

- каталог товаров;
- карточки продукции;
- адаптивная верстка;
- навигация по основным разделам магазина;
- интерфейс корзины;
- персонализация изделий;
- оформление в едином стиле бренда;
- корректное отображение на мобильных устройствах.

## Запуск проекта

Для локального запуска потребуется установленный Node.js.

Клонируйте репозиторий:

```bash
git clone https://github.com/USERNAME/shagreen.git
```

Перейдите в папку проекта:

```bash
cd shagreen
```

Установите зависимости:

```bash
npm install
```

Запустите dev-сервер:

```bash
npm run dev
```

После запуска Vite покажет локальный адрес проекта в терминале.

## Сборка

Для создания production-сборки:

```bash
npm run build
```

Для локальной проверки готовой сборки:

```bash
npm run preview
```

## Структура

Основной код приложения находится в папке `src`.

```text
src/
├── assets/
├── components/
├── App.jsx
└── main.jsx
```

Компоненты интерфейса вынесены отдельно от основной композиции страницы, чтобы проект было проще поддерживать и развивать.

## Статус

Проект завершён как портфолио-кейс.

В дальнейшем отдельные элементы интерфейса и функциональность могут дорабатываться.
